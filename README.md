# Fireboy Vuegirl Set up Guide

This guide walks you through setting up your developer environment for building full-stack solution using Vue and Firebase step by step. 

Prerequisites

- Node.js 20 or higher (https://nodejs.org/en/download)
- A google account (for firebase console)
- Git (https://git-scm.com/)
- github account
- Basic HTML understanding
- IDE (e.g. Visual Studio Code, Jet Brain Web Storm, Visual Studio etc)

### Clone Repository

<aside>
💡

Open up an IDE of your liking and fork and clone this repo

</aside>

Once cloning the repository, make sure you’re in
 Your-Folder\vue-project> 
then run these commands

```bash
npm install
npm install firebase
```

Wait for it to load then your codebase is ready to go! Now let's move on to setting up the firebase console
